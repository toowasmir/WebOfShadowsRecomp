# Spider-Man: Web of Shadows Recompiled — Logs

This directory stores session and diagnostic crash logs generated by the game engine.

- **`wos_recomp_latest.log`**: Diagnostic log from the most recent game run.
- **`wos_session_YYYYMMDD_HHMMSS.log`**: Archived session logs (the launcher automatically preserves up to the 10 most recent sessions).

### Submitting a Bug Report
If you experience a crash, graphical glitch, or unexpected behavior:
1. Open **`WoS_Launcher.exe`** and navigate to the **📊 Stats** (or **Analiz**) tab.
2. Click **📦 Export Bug Report (.ZIP)** (`Hata Raporu (.ZIP) Oluştur`).
3. Attach the generated `WoS_BugReport_<timestamp>.zip` file directly to a new issue on the [GitHub Issues page](https://github.com/toowasmir/WebOfShadowsRecomp/issues).
